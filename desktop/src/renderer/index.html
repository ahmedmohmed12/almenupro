توكن Talabat Vendor API

Vendor ID والتوكن الرسمي يُحفظان مشفّرين ولا يظهر التوكن بعد الحفظ. إذا كانت الحالة «محفوظ»، اضغط إعادة الفحص — أو الصق JWT جديد فقط عند التجديد.

مكان نسخ التوكن (يدويًا)

  1. اضغط «فتح Network» — يفتح أدوات المطوّر على Talabat.
  2. في Network الصق الفلتر أدناه واضغط Enter.
  3. اختَر طلب فيه /vendors/…/orders.
  4. من Headers انسخ بعد Bearer والصقه فوق.

التطبيق لا يعرض توكن الجلسة تلقائيًا — انسخه أنت من Network فقط.
